Glossary

Terms in this walkthrough

Client
The program asking another program to do work. Here, the website backend asks Greeter.
Server / service
The program that receives the request and runs the method. Here, Greeter answers.
RPC
Remote procedure call: invoking a named method in another process over a network.
Encoding
Turning a structured value such as Name: "Ada" into bytes that can travel over a network.
Decoding
Rebuilding a structured value from the received bytes.
Protobuf
A way to define message fields and services; it also has a compact binary encoding.
Unary call
One request followed by one response.
Streaming
A call that can carry multiple messages over time.
Transport
The network rules that move the encoded messages, such as HTTP/1.1 or HTTP/2.
gRPC
An RPC framework that typically uses protobuf messages over HTTP/2 and supports streaming calls.
Twirp
An RPC framework for unary calls that uses a .proto contract and ordinary HTTP POST.
HTTP/1.1
A widely supported version of HTTP that Twirp can use.
HTTP/2
A newer version of HTTP used by gRPC; it supports multiple streams on one connection.

Sources: gRPC concepts, Twirp protocol, Twitch's rationale.
